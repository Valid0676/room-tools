    Setting up
    • Run python x32_bridge.py in this folder and use the page it opens (http://localhost:8032). Browsers can't talk to the desk directly; the bridge passes the messages on.
    • The laptop and the X32 must be on the same network. Find the desk's IP under Setup › Network.
    • Noise path: send the noise into one desk channel (for example a USB card return), with that channel's EQ and dynamics flat, assigned to Main LR at unity.
    • Mic path: set the reference mic's preamp so the meter sits around −20 dBFS with the noise playing. If the X32 is your USB interface, route the mic's channel to a card output and pick that channel here.
    • Graphic EQ mode needs a GEQ or TruEQ already inserted on Main LR (Effects slot, then Main LR › Insert).
